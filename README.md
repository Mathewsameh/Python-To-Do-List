# Python To-Do List

## About the Project

A simple To-Do List application built with Python. It allows users to manage their daily tasks through a menu-driven interface.

## Features

* Show all tasks
* Add new tasks
* Delete tasks
* Save tasks in a text file (`tasks.txt`)
* Simple menu and input validation

## Technologies Used

* Python
* Jupyter Notebook
* Text File Handling

## Project Files

* `To Do List.ipynb` — The main Python project.
* `tasks.txt` — Stores the tasks.

## How to Run

1. Download or clone this repository.
2. Open `To Do List.ipynb` in Jupyter Notebook.
3. Run the notebook cells.
4. Use the menu to manage your tasks.
